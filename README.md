# MediStock | Medical Inventory Management Platform

**A Full-Stack Inventory Intelligence Platform for Healthcare Organizations**

MediStock is a team-developed full-stack application built during the **Infosys Springboard Virtual Internship 7.0 – Batch 3**. It is designed to simplify medical inventory operations by bringing medicine management, stock monitoring, supplier information, expiry tracking, and inventory analytics into a centralized platform.

## Project Overview

Managing medical inventory requires accurate stock records, timely expiry monitoring, and visibility into medicine availability. MediStock addresses these operational needs through a web-based platform that connects a React frontend with a Spring Boot backend and a relational database.

## Core Capabilities

- **Authentication:** Email and password-based registration and login, BCrypt password hashing, and JWT-based authentication.
- **Medicine Management:** Create, view, and update medicine records.
- **Inventory Management:** Track medicine quantities and manage stock updates.
- **Supplier Management:** Maintain supplier information and associated records.
- **Search and Filtering:** Find and filter medicine records using inventory-related attributes.
- **Expiry Monitoring:** Identify expired and soon-to-expire medicines.
- **Stock Alerts:** Monitor low-stock and out-of-stock conditions.
- **Analytics Dashboard:** View inventory summaries and stock-related insights.
- **Reporting:** Access inventory reports and supported export functionality.
